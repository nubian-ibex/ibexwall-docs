# ADR-0018: FOSS first, managed later (D-018)

- Status: Accepted
- Date: 2026-11-01

## Context

Trust for a security product is earned in the open before enterprise
conversations.

## Decision

Ship the open client to v1.0 first; build the waitlist and design
partners in parallel; the managed tier starts after the open contracts
are proven.

## Consequences

- Roadmap phases F0-F10 avoid any proprietary dependency.
- F11 lands the open managed-mode contracts before the proprietary
  plugin exists.
