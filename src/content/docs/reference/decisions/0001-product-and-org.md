# ADR-0001: Product and organization (D-001)

- Status: Accepted
- Date: 2026-11-01

## Context

A single brand must cover the product, the GitHub organization and the
future domains.

## Decision

Product: **IbexWall — Security Center for Linux**. Organization:
**Nubian Ibex** on GitHub (`nubian-ibex`).

## Consequences

- All naming flows from here (ADR-0002); domain acquisition is tracked
  as pending P-01.
